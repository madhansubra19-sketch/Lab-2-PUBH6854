Lab 2 analysis — R

Primary Biliary Cholangitis Data from Mayo Clinical Trial conducted between 1974 and 1984. A total of 424 PBC patients, referred to Mayo Clinic during that ten-year interval, met eligibility criteria for the randomized placebo controlled trial of the drug D-penicillamine. The first 312 cases in the data set participated in the randomized trial and contain largely complete data. The additional 112 cases did not participate in the clinical trial, but consented to have basic measurements recorded and to be followed for survival. Six of those cases were lost to follow-up shortly after diagnosis, so the data here are on an additional 106 cases as well as the 312 randomized participants.

Primmary Biliary Cholangitis (PBC) is an autoimmune disease which leads to the destruction of small bile ducts in the the liver.

Question 2

q2 <- pbc %>%
  select(id, status, time, bili, albumin) %>%
  mutate(
    died = status == 2,
    # Split into quartiles (Q1 = lowest)
    bili_group = factor(paste0("Q", ntile(bili, 4))),
    alb_group = factor(paste0("Q", ntile(albumin, 4)))
  )

Is bilirubin a prognostic biomarker? Or Albumin?

#Is bilirubin a prognostic biomarker?
bili_rate <- q2 %>%
  group_by(bili_group) %>%
  summarize(died = mean(died, na.rm = TRUE))

#Is albumin a prognostic biomarker?
alb_rate <- q2 %>%
  group_by(alb_group) %>%
  summarize(died = mean(died, na.rm = TRUE))
ggplot(bili_rate, aes(x = bili_group, y = died)) +
  geom_col(fill = "steelblue") +
  coord_cartesian(ylim = c(0, 1)) +
  labs(
    title = "Death rate by bilirubin quartile",
    x = "bilirubin quartile (Q1 = lowest)",
    y = "proportion died"
  ) +
  theme_minimal()

ggplot(alb_rate, aes(x = alb_group, y = died)) +
  geom_col(fill = "steelblue") +
  coord_cartesian(ylim = c(0, 1)) +
  labs(
    title = "Death rate by albumin quartile",
    x = "albumin quartile (Q1 = lowest)",
    y = ""
  ) +
  theme_minimal()

Analysis of data statement

Based on the analysis we see that Bilirubin slightly increase by PBC stage, while albumin stays realtively steady at each PBC stage. Death Rate was determined by finding the status of those who have been declared dead, splitting bilirubinlalbumin into quartiles and then finding the proportion of those who died in each quartile of bilirubin/albumin amounts. Based on the data we see that as bilirubin increases the rate of death increases, while the inverse is true albumin, with decline death rates as albumin increases.

Closing: Comparison of R Markdown Vs Jupyter Notebook

When Comparing the two implementations the, I felt that using the R markdown file was faster to write since differentiating between code chunks and actual writing/headings is a bit more defined. In the Jupyer Notebook we have to manually change each chunk to either code or markdown, which is fine but I feel takes a bit more time. One thing I noticed wehn comapring the two notebooks is that the boxplots created for the bilirubin and albumin by stage analysis slightly differed. This is due to how ggplot vs matplotlib handle labeling the axes.. ggplot writes the rick labels in real unit while matplotlib writes them in the powers of ten and picks its own range.
